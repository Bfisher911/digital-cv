# Milestone 1 Page Content Briefs

These briefs translate the sitemap into build-ready content direction. They are intentionally more detailed than the wireframes. The goal is to make Milestone 2 an implementation pass, not another discovery pass.

All copy below uses confirmed facts from the rebuild brief or the current repo. Anything that needs confirmation remains marked with `[FLAG: verify with Dr. Fisher]`.

## Editorial Baseline

| Rule | Application |
| --- | --- |
| Voice | Thoughtful, observant professor voice with executive altitude |
| Point of view | First person only on `/about`; third person everywhere else |
| Fact discipline | No invented facts, dates, clients, collaborators, testimonials, URLs, or asset availability |
| Title discipline | Use `Senior Instructional Technology Manager` where the Tulane job title appears; use `senior academic technology executive` for positioning |
| Consulting discipline | Sparkfish Consulting appears as a separate advisory practice, with its own route and experience card |
| Visual discipline | MU-TH-UR 6000 terminal language stays foundational across the site |
| Content density | Each page should answer what Dr. Fisher does, why it matters, what evidence supports it, and where the reader should go next |

## Global Content Patterns

| Pattern | Purpose | Routes |
| --- | --- | --- |
| Terminal status line | Gives each route an in-world label without reducing clarity | All routes |
| Proof rail | Surfaces metrics, dates, organizations, and identifiers near the top of each page | `/`, `/experience`, `/research`, `/book`, `/speaking`, `/consulting` |
| Thread cards | Keeps the six career threads visible without flattening them | `/`, `/about`, `/experience` |
| Evidence cards | Turns claims into scannable proof points | `/experience`, `/teaching`, `/research`, `/publications`, `/speaking` |
| Related route panels | Moves readers through the professional hub by intent | All long-form routes |
| Flagged placeholders | Keeps uncertain material visible during review without shipping invented facts | Planning docs and draft content |
